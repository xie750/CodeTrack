题目描述

删除第 pos 个节点并返回新的头指针。

知识点

链表 指针

公开样例

pos=1 时返回新的 head。

代码编辑器

Node* deleteAt(Node* head,int pos){
  if(head==NULL) return head;
  Node* cur=head;
  for(int i=1;i<pos-1&&cur;i++){
    cur=cur->next;
  }
  if(cur && cur->next){
    Node* t=cur->next;
    cur->next=t->next;
    delete t;
  }
  return head;
}
