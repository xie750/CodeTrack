# 教师端知识图谱复用说明

本文档用于在其他项目中复刻 SparkLearn 教师端知识图谱功能。把本文档的“可直接交给 AI 的复刻提示词”整段发给 AI，即可要求它生成一个视觉、交互、数据结构和生成逻辑都尽量一致的教师端知识图谱模块。

参考实现位置：

- 前端页面：`frontend/src/app/(teacher)/teacher/knowledge-graph/page.tsx`
- API 封装：`frontend/src/lib/api/real.ts`
- 类型定义：`frontend/src/lib/api/types.ts`
- 后端接口：`backend/app/routes/teacher_graph.py`
- 数据表：`backend/app/db.py` 中的 `teacher_knowledge_graphs`

## 当前实现的核心模型

### 节点类型

教师端当前生效节点类型只有 6 类：

| 类型 | 颜色 | 用途 |
| --- | --- | --- |
| 知识点 | `#2563eb` | 默认知识节点 |
| 概念 | `#2563eb` | 概念定义、术语理解 |
| 方法 | `#0f766e` | 方法、步骤、策略、算法 |
| 公式 | `#7c3aed` | 公式、定理、法则 |
| 案例 | `#d97706` | 案例、例题、实践、项目 |
| 能力 | `#dc2626` | 能力目标、素养目标 |

注意：`frontend/src/lib/api/types.ts` 中历史类型仍包含“包含、应用、易混淆”等关系名，但教师端页面和后端清洗逻辑当前只使用“前驱、后继、相关”。迁移时以本文档为准。

### 关系类型

| 类型 | 视觉 | 语义 |
| --- | --- | --- |
| 前驱 | 浅灰蓝实线，较粗 | A 是 B 的前置知识 |
| 后继 | 青色实线 | A 学完后进入 B |
| 相关 | 浅蓝虚线 | A 与 B 有关联但不是严格先后 |

后端兼容“前置知识”，会自动映射为“前驱”。

## 图谱生成逻辑

### LLM 提示词

后端生成时使用类似以下提示词。迁移时建议原样保留结构约束：

```text
你是教师端知识图谱构建助手。请从资料中抽取 8 到 16 个知识点节点和它们之间的关系。只输出 JSON，不要 Markdown。JSON 结构：{"description":"一句话概括","nodes":[{"label":"知识点","type":"概念|方法|公式|案例|能力","description":"不超过40字","difficulty":1}],"edges":[{"source":"节点名","target":"节点名","type":"前驱|后继|相关"}]}。关系类型只能从“前驱、后继、相关”中选择。
图谱标题：{title}
资料内容：
{sample}
```

其中 `sample` 为上传资料合并文本的前 6000 字。

### 归一化规则

- LLM 输出允许被包在 Markdown code fence 中，后端应能提取 `{...}` JSON。
- 节点最多保留 18 个，关系最多保留 32 条。
- 节点必须有唯一 `label`，空 label 和重复 label 丢弃。
- 节点 ID 使用 `node-` 加 8 位随机字符串。
- 关系 ID 使用 `edge-` 加 8 位随机字符串。
- 关系的 `source`、`target` 先按节点 label 匹配，再转换为节点 ID。
- 如果没有有效关系，则对节点顺序生成连续边。

### 兜底生成

如果 LLM 失败或没有返回节点：

1. 从上传文本中提取候选标题行：去掉 Markdown 标记、序号、项目符号。
2. 从文本中统计中文、英文、数字、`_+#/` 组成的 2-18 字 token。
3. 去掉常见停用词：以及、或者、可以、进行、通过、一个、我们、你们、他们、使用、学习、知识、内容。
4. 合并短行和高频词，去重并避免包含关系重复。
5. 生成 6-14 个节点。
6. 按顺序生成边：前半部分“前驱”，后半部分“相关”。

## 复刻验收清单

- 上传 `.pdf/.docx/.md/.txt` 后能生成 8-16 个左右节点的草稿图谱。
- 图谱列表能显示标题、状态、节点数、关系数。
- 点击列表项能恢复完整节点和关系。
- 点击节点能在属性面板编辑名称、类型、难度和说明。
- 修改节点类型后颜色同步变化。
- 点击关系能编辑关系类型，并显示起点和终点。
- 连接模式能按“起点 -> 终点”创建关系。
- 同一对节点同一关系类型不能重复创建。
- 删除节点时会同步删除所有关联关系。
- 保存草稿后刷新页面数据仍存在。
- 发布后状态变成“已发布”，列表和来源资料面板同步显示。
- 空图谱显示空状态。
- ECharts 支持滚轮缩放、拖动画布和拖拽节点。
- 画布在窗口变化时能 resize，不出现空白或挤压。
