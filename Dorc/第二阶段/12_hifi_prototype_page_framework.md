# 高保真原型页面框架

## 0. 原型口径

本原型面向赛题中的“专业垂直类学科数据处理与智能应用”要求，平台垂直学科先固定为：

> 计算机学科 / 计算机类专业方向

首版演示样例：

```text
平台垂直大类：计算机学科
-> 专业方向：软件工程
-> 行政班：软件工程 1 班
-> 课程：数据结构与程序设计基础
-> 知识点：链表、栈与队列、二叉树
```

本文件只用于高保真产品原型设计，重点呈现页面、控件、功能和业务状态。

## 1. 设计依据合并

| 来源 | 对原型的要求 | 页面落点 |
| --- | --- | --- |
| 当前学生业务流程 | 学生端采用与教师端一致的两层工作台逻辑：先进入学生工作台，再加入班级；加入后工作台出现对应班级课程，点击班级课程进入子工作空间完成任务、自学和 AI 助学 | 学生工作台、加入班级、班级课程、班级课程工作空间、任务工作台、任务完成总结 |
| 教师端联动 | 教师创建课程、绑定班级、邀请学生、下发任务、查看提交反馈和画像聚合 | 教师工作台、课程工作空间、授课班级、邀请学生、作业任务、任务反馈、学情分析 |
| 讯飞智慧教育参考 | 借鉴“资源 + 数据 + AI + 教学闭环”，课程资源进入知识库，服务 AI 检索、精准辅导和学情分析 | 教学材料、课程知识库、知识图谱、AI 检索测试、AI 诊断、教学优化建议 |
| 赛题要求 | 体现学科垂类、真实教学场景、智能体应用、个性化学习、可信引用和可追溯内容 | 业务流程页、学生任务链路、AI 助学、学习画像、资料库、教师学情分析 |
| 会议要求 | 先讲清学生端“工作台 -> 加入班级 -> 班级课程 -> 子工作空间”的主流程；AI 助学用精灵悬浮窗口，不做完整教务和助研 | 学生端优先级、AI 精灵悬浮窗口、教师端支撑页面、管理员轻量页面 |

## 2. 总业务流程

### 2.1 学生主流程

```text
学生首次登录
-> 进入学生工作台
-> 加入班级
-> 工作台出现对应班级课程
-> 点击班级课程进入子工作空间
-> 查看教师下发任务
-> 进入任务工作台
-> 编写 / 运行 / 提交代码
-> 遇到问题唤起 AI 助学精灵
-> 查看 AI 诊断、引用来源和分层提示
-> 修改后重新提交
-> 完成任务
-> 生成学习总结
-> 更新学习画像
-> 保存学习资料
-> 推荐下一步学习
```

### 2.2 教师支撑流程

```text
教师登录
-> 创建课程
-> 进入课程工作空间
-> 绑定授课班级
-> 邀请学生加入
-> 上传课程资料
-> 构建课程知识库 / 知识图谱
-> 创建并发布任务
-> 查看学生提交反馈
-> 查看班级学情和学生画像聚合
-> 调整教学或发布复习任务
```

### 2.3 数据回传流程

```text
学生提交
-> 沙箱执行结果
-> AI 诊断与提示记录
-> 学习总结
-> 学生画像更新
-> 我的资料库沉淀
-> 教师端任务反馈
-> 班级学情分析
-> 教学优化建议
```

## 3. 学生端页面

### 3.1 学生端层级

| 层级 | 页面框架 | 主要控件 | 功能说明 |
| --- | --- | --- | --- |
| 学生工作台 | 登录后的学生全局窗口，左侧学生导航，中间班级课程入口，右侧待办 / 画像摘要，右下角 AI 精灵 | 工作台首页、加入班级、班级课程卡、今日待办、学习画像摘要、最近资料、AI 快问 | 对齐教师端工作台心智。学生先看到自己加入了哪些班级课程，以及当前应该进入哪个课程空间。 |
| 加入班级 | 工作台内的加入窗口或独立引导页 | 邀请码、扫码、邀请链接识别、班级预览、课程预览、确认加入 | 承接教师端邀请。学生加入的是教师端已配置的班级课程关系。 |
| 班级课程 | 学生工作台中的课程卡片区 | 班级名称、课程名称、授课教师、未完成任务数、最近学习状态、进入按钮 | 加入成功后自动出现。班级和课程是连在一起的，不让学生自己重新创建课程。 |
| 班级课程工作空间 | 点击某个班级课程后进入的子窗口，顶部显示班级 + 课程，左侧为该课程菜单 | 课程首页、课程任务、自主学习、AI 助学、我的资料、画像摘要、返回工作台 | 与教师端“课程工作空间”一致，只是学生视角只看自己的任务、资料和画像。 |
| 任务工作台 | 班级课程工作空间内的深页面，左侧任务说明，中间代码编辑器，右侧验证与 AI 面板 | 题目说明、公开样例、代码编辑器、运行、提交、测试结果、AI 诊断、分层提示、版本记录 | 完成教师下发的编程训练、查看诊断、获取提示、重新提交。 |

### 3.2 首次登录与加入流程页面

| 页面 | 页面框架 | 主要控件 | 功能说明 |
| --- | --- | --- | --- |
| 学生首次欢迎页 | 学生工作台空状态、加入入口、右侧示例班级课程预览 | 开始加入、输入邀请码、扫码加入、打开邀请链接、进入自主学习 | 学生第一次登录后先进入工作台；如果没有班级课程，工作台显示加入引导。 |
| 加入班级 | 工作台内加入窗口、班级课程识别预览、状态反馈 | 邀请码输入框、扫码入口、链接识别、重新输入、确认加入、联系教师提示 | 承接教师分享的邀请码、二维码或链接，识别教师端配置好的班级、课程、教师和学期。 |
| 加入确认页 | 班级课程摘要、教师信息、加入说明 | 确认加入、取消、查看课程说明 | 防止学生误加入，确认后把该班级课程加入学生工作台。 |
| 加入成功页 | 成功反馈、当前班级课程卡、下一步动作区 | 返回工作台、进入班级课程、查看课程任务、继续加入其他班级 | 加入后工作台出现对应班级课程卡，学生点击卡片进入子工作空间。 |
| 未加入空状态 | 学生工作台空状态、加入入口、自主学习入口 | 输入邀请码、扫码、打开链接、联系教师、进入自主学习 | 学生尚未加入任何班级课程时展示，不出现无意义数据卡。 |

### 3.3 学生工作台细化

| 模块 | 页面框架 | 主要控件 | 功能说明 |
| --- | --- | --- | --- |
| 班级课程卡 | 工作台主区域 | 班级名称、课程名称、授课教师、未完成任务数、最近提交状态、进入课程空间 | 学生加入班级后自动生成，对应教师端的班级课程关系。 |
| 今日待办 | 工作台主区域顶部 | 任务标题、所属班级课程、截止时间、状态、立即继续 | 聚合所有班级课程下的待完成任务。 |
| 学习画像摘要 | 工作台右侧面板 | 总进度、薄弱点、提示依赖、最近错因、查看详情 | 展示学生总体学习状态，也可进入班级课程空间后查看课程级画像。 |
| 下一步推荐 | 工作台中部列表 | 推荐标题、推荐原因、关联班级课程、关联知识点、开始学习 | 根据任务、错因、提示使用和画像给出行动建议。 |
| 最近资料 | 工作台下方列表 | 资料类型、班级课程、知识点、来源、继续学习 | 展示最近保存的总结、笔记、卡片和错题归因。 |
| AI 快捷入口 | 工作台右下角悬浮精灵和快捷问题 | 推荐问题、输入框、展开完整页 | 让学生快速询问“先进入哪个课程”“先做哪个任务”“哪里薄弱”。 |

### 3.4 班级课程工作空间细化

| 页面 | 页面框架 | 主要控件 | 功能说明 |
| --- | --- | --- | --- |
| 班级课程首页 | 顶部显示班级 + 课程，左侧课程菜单，中间课程概览，右侧画像 / AI 面板 | 返回工作台、课程任务、课程进度、教师信息、最近任务、薄弱知识点、AI 精灵 | 点击工作台中的班级课程卡后进入，是学生侧的子窗口。 |
| 课程任务 | 顶部筛选、任务卡列表、右侧截止提醒 | 状态 Tab、搜索、排序、任务卡、进入任务 | 只展示当前班级课程下教师发布给该学生的任务。 |
| 自主学习 | 左侧知识点树、中间学习路径、右侧 AI 生成器 | 知识点选择、生成讲解、生成练习、保存资料 | 围绕当前班级课程知识点学习。 |
| AI 助学 | 对话流、引用来源、动作面板 | 当前班级课程上下文、问题输入、引用来源、置信度、生成练习、保存笔记 | AI 默认带入当前班级课程、任务和画像上下文。 |
| 我的资料 | 类型筛选、资料列表、预览抽屉 | 类型 Tab、知识点筛选、课程内资料、继续提问 | 展示当前班级课程下沉淀的学习资料。 |
| 画像摘要 | 右侧面板或抽屉 | 课程进度、薄弱点、高频错因、提示依赖、证据来源 | 展示当前班级课程维度的学习画像。 |

### 3.5 课程任务页细化

| 页面状态 | 页面框架 | 主要控件 | 功能说明 |
| --- | --- | --- | --- |
| 全部任务 | 顶部筛选、任务卡列表、右侧提醒 | 状态 Tab、搜索、排序、任务卡 | 展示当前班级课程工作空间内的教师下发任务。 |
| 未开始 | 任务卡突出开始入口 | 开始任务、查看说明、截止提醒 | 帮学生快速进入新任务。 |
| 进行中 | 展示最近提交摘要 | 继续任务、最近结果、上次诊断 | 承接学生未完成的训练。 |
| 待修正 | 展示失败原因摘要 | 继续修改、查看诊断、查看提示 | 引导学生回到任务工作台修正错误。 |
| 已完成 | 展示总结和资料入口 | 查看总结、保存资料、复习相关知识点 | 完成后可继续沉淀学习资料。 |
| 已截止 | 弱化主操作，突出结果 | 查看记录、查看教师反馈 | 保留历史记录，不再误导学生继续提交。 |

任务卡字段：

```text
任务标题 / 所属课程 / 发布教师 / 知识点 / 难度 / 截止时间
当前状态 / 最近一次提交摘要 / 提示开放级别 / 进入任务按钮
```

### 3.6 任务工作台细化

| 区域 | 页面框架 | 主要控件 | 功能说明 |
| --- | --- | --- | --- |
| 左侧任务说明 | 固定说明栏，可折叠 | 题目描述、输入输出要求、知识点、公开样例、评分要求 | 帮学生理解任务目标和边界条件。 |
| 中间代码区 | 稳定高度代码编辑器，上方工具栏，下方操作栏 | 语言选择、代码编辑器、运行、提交、重置、版本切换 | 承载核心编程训练，不被 AI 面板遮挡。 |
| 右侧系统验证 | 诊断栏上半部分 | 编译状态、测试通过数、失败用例摘要、运行日志复制 | 先呈现工具事实，AI 不能覆盖系统验证结果。 |
| 右侧 AI 诊断 | 诊断栏中部 | 错因类型、分步解释、关联知识点、引用来源、置信度、下一步动作 | 基于测试结果、课程知识库和学生画像解释问题。 |
| 右侧分层提示 | 诊断栏下部 | 一级提示、二级提示、三级提示、解锁说明、风险提示 | 按教师设置开放，不直接给完整答案。 |
| 完成总结 | 任务通过后出现 | 本次总结、主要错因、提示使用、画像变化、保存资料、下一步推荐 | 完成后沉淀资料并更新画像。 |

任务工作台状态：

| 状态 | 触发条件 | 页面反馈 |
| --- | --- | --- |
| 默认态 | 学生刚进入任务 | 展示题目、样例、编辑器和提交入口。 |
| 运行中 | 点击运行或提交 | 显示沙箱执行中、按钮 loading、排队提示。 |
| 编译失败 | 编译不通过 | 显示编译错误、复制日志、AI 解释入口。 |
| 测试未通过 | 部分用例失败 | 显示失败摘要、AI 诊断、一级提示。 |
| 查看提示 | 学生主动点击提示 | 记录提示等级，更新提示依赖数据。 |
| 重新提交 | 学生修改后再次提交 | 生成新版本，保留旧版本诊断。 |
| 任务完成 | 必要测试通过 | 展示总结、资料保存和画像更新。 |

### 3.7 AI 助学精灵悬浮窗口

| 状态 | 页面框架 | 主要控件 | 功能说明 |
| --- | --- | --- | --- |
| 收起态 | 右下角悬浮圆形图标 | AI 图标、未读点、tooltip | 全局可见，不遮挡运行、提交、保存等关键按钮。 |
| 展开态 | 小型悬浮窗口 | 当前上下文标签、推荐问题、输入框、发送、关闭、展开完整页 | 学生不离开当前页面即可求助。 |
| 任务诊断态 | 悬浮窗口显示诊断摘要 | 错因摘要、查看引用、查看提示、同步到右侧面板 | 任务工作台中用于快速理解错误。 |
| 学习建议态 | 展示下一步推荐 | 推荐班级课程、推荐任务、推荐知识点、生成练习、保存笔记 | 学生工作台和自主学习中用于导航。 |
| 低置信度态 | 风险提示样式 | 引用不足、置信度、继续追问、查看来源 | AI 不确定时明确提示学生核查。 |

```text
AI 生成标识
当前上下文
是否结合画像
引用来源
置信度
风险提示
下一步动作
保存到资料库
```

## 4. 教师端页面

### 4.1 教师端层级

| 层级 | 页面框架 | 主要控件 | 功能说明 |
| --- | --- | --- | --- |
| 教师工作台 | 登录后的全局窗口，左侧侧边栏，中间工作区，右侧待办或消息 | 工作台首页、课程、任务待办、消息提醒、个人设置、新建课程 | 管理教师自己的全部课程入口，不直接承载某一门课程的深层教学操作。 |

| 邀请学生加入 | 当前课程与班级筛选、邀请方式卡片、学生名单预览、加入状态列表 | 班级选择、批量导入、Excel/CSV 上传、分享链接、二维码、班级邀请码、复制、重置邀请码、加入审批开关 | 生成学生首次登录时使用的邀请码、链接或二维码。 |
| 上传课程资料 | 左侧资料上传、中间资料列表、右侧解析与引用预览 | 上传文件、添加链接、资料类型、绑定知识点、解析状态、引用片段预览、可信来源标记、删除 / 重传、继续构建知识库 | 教师上传讲义、课件、实验指导、代码规范等资料。 |
| 构建课程知识库 | 分步处理状态、知识点映射、索引结果、教师确认区 | 文档解析状态、切片数量、知识点覆盖率、索引状态、低质量片段、人工确认、重新解析、发布到知识库 | 将资料变成 AI 可检索的课程知识来源。 |
| 构建课程知识图谱 | 图谱画布、知识点树、关系编辑区、AI 推荐区 | 新增知识点、编辑前置关系、资料证据绑定、AI 自动抽取、人工确认、发布图谱 | 支撑学习路径推荐、AI 问答引用和薄弱点定位。 |
| AI 检索测试 | 左侧试问输入、中间回答结果、右侧引用证据 | 测试问题输入、运行检索、引用来源、可信度、置信度、可执行度、采纳 / 退回 | 教师检查知识库是否能支撑学生 AI 回答。 |
| 资料质量检查 | 资料覆盖率面板、知识点映射表、问题列表 | 覆盖率指标、未覆盖知识点、低质量资料提示、重新解析、人工确认引用、补充资料 | 避免 AI 缺少课程来源后凭空回答。 |
| 创建首个任务向导 | 当前课程内分步任务表单、题目预览、发布确认 | 任务类型、题目标题、题目说明、知识点选择、测试用例配置、截止时间、提示开放级别、下发班级、预览学生视角、发布 | 在当前课程内创建学习任务，并按班级下发。 |
| 发布成功页 | 成功反馈、任务摘要、下一步动作区 | 查看任务、继续创建、复制学生入口、进入学情页 | 发布后提示任务已进入学生端，并给教师观察入口。 |

## 8. 原型优先级

第一轮优先画学生端完整承接闭环：

```text
学生首次欢迎页
-> 学生工作台空状态
-> 加入班级
-> 加入确认
-> 加入成功
-> 学生工作台出现班级课程
-> 点击班级课程
-> 班级课程工作空间首页
-> 课程任务列表
-> 任务详情预览
-> 任务工作台
-> 系统验证失败
-> AI 助学精灵展开
-> AI 诊断与分层提示
-> 重新提交
-> 任务完成总结
-> 学习画像更新
-> 我的资料库
-> 下一步推荐
```

第二轮补教师端支撑闭环：

```text
教师工作台
-> 课程列表
-> 创建课程
-> 课程工作空间
-> 授课班级
-> 邀请学生加入
-> 教学材料
-> 课程知识库
-> 课程知识图谱
-> AI 检索测试
-> 创建并发布任务
-> 任务提交反馈
-> 学情分析
-> 学生画像
-> 教学优化建议
```

第三轮补管理员初始化页面，只做基础数据配置。
