# 交互与静态数据检查记录

## 范围

本轮从第二阶段文档、当前路由、点击处理函数和 API 数据流开始检查，重点修复学生端入口、课程工作台、收藏夹以及管理员端导入和公告的可复现问题。检查了教师端页面的占位交互，并运行两个后端的现有测试。

保留开始检查时已有的修改。本轮没有修改数据库结构、后端接口、沙箱执行、AI 诊断、教师发布/批改流程，也没有重写页面布局。

## 数据边界与仍存在的原型内容

- **管理员账户、公告仍基于 `admin/stores/useAppStore.ts` 的内存演示数据。** 导入仅更新本次会话列表，不创建可登录账号；公告不会发送给师生。界面已说明刷新后恢复，不把这些操作描述成服务端持久化。
- 导入现在实际支持 **CSV UTF-8**。原先 `.xlsx/.xls` 入口没有解析能力；界面改为明确提示 Excel 另存为 CSV，未引入新的 Excel 解析依赖。
- 管理员看板的部分历史趋势、模拟账户统计，以及示例课表仍需后续对接对应业务接口。本轮没有把演示内存状态冒充真实后端，也没有扩大到权限、通知投递或教务排课重构。
- 收藏记录继续使用既有按用户隔离的本地存储；编程任务状态从既有 API 同步。单道试题收藏的得分快照没有被整套测验进度覆盖。
- 浏览器验证使用明确的 API 测试夹具，验证交互与失败分支；不代表已对真实模型服务或生产数据完成全流程验收。

## 验证

- `cd frontend; npm run build`：通过。仍有原有的大包体积提示。
- `cd frontend; node scripts/verify-interactions.mjs`：通过。覆盖教师/学生导入、模板下载、重复/无效文件校验、公告编辑与第二页拖拽、收藏进度与筛选、AI 上下文、失效路径、课程接口部分失败和加入成功后的刷新失败。浏览器无未捕获异常。

- `git diff --check`：通过。

### 复跑浏览器检查

在 `frontend` 下先运行：

```powershell
node node_modules/vite/bin/vite.js --host 127.0.0.1 --port 5174 --strictPort
```

```powershell
node scripts/verify-interactions.mjs
```
