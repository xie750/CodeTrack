# CodeTrack 作品源码说明

## 源码位置

当前工作区根目录 `D:\shy\CodeTrack` 即为 CodeTrack 作品源码目录。源码包含学生端、教师端、后端服务、沙箱执行链路、种子数据、测试和部署配置。

主要目录如下：

| 路径 | 作用 |
| --- | --- |
| `backend` | 学生端后端、AI 工作流、课程任务、学习画像、资料库和模型接入 |
| `teacher_backend` | 教师端后端和教师端数据持久化 |
| `frontend` | React + TypeScript + Vite 前端 |
| `sandbox` | 编程任务执行和测试相关代码 |
| `deploy` | Docker Compose 和部署说明 |
| `tests` | 后端和端到端验证测试 |
| `scripts` | 种子数据、文档和验证辅助脚本 |
| `Dorc/第二阶段` | 当前阶段产品范围、页面和工程设计依据 |

## 推荐启动顺序

1. 安装 Python 依赖和前端依赖。
2. 配置 `.env`，模型配置可暂时留空，系统会使用规则兜底完成基础演示。
3. 执行 `python scripts/seed_demo.py` 准备演示数据。
4. 启动后端服务。
5. 在 `frontend` 目录执行 `npm run dev` 启动前端。

## 当前实现的模型接入位置

- `backend/app/services/model_gateway.py`：代码诊断模型层，负责构造任务、提交、测试结果和知识源 payload，并校验模型输出。
- `backend/app/ai/llm_client.py`：负责调用模型网关或 OpenAI 兼容接口。
- `backend/app/core/config.py`：读取模型网关、模型名称、模型 API 地址和微调模型配置。
- `.env.example`：提供不含密钥的配置示例。
- `deploy/docker-compose.yml`：提供容器化部署时的模型配置入口。
