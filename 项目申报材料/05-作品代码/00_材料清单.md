# 作品代码材料清单

本目录用于整理 CodeTrack 项目当前可提供的作品代码、模型文件、技术说明和验证材料。

## 目录结构

| 目录 | 内容 | 当前状态 |
| --- | --- | --- |
| `01_作品源码` | 源码位置、启动方式和源码归档说明 | 已整理 |
| `02_模型文件或模型ServiceID` | `codetrack-q4_k_m.gguf` 及模型接入说明 | 已提供模型文件 |
| `03_数据与知识库材料` | 数据、课程知识源和 RAG 材料说明 | 项目有种子数据和知识库链路，未提供微调数据集 |
| `04_技术报告` | 技术架构、模型接入和复现边界说明 | 已整理 |
| `05_复现说明` | 面向评审和技术人员的模型复现说明 | 已整理 Word 文档 |
| `06_验证材料` | 验证命令、验证结果和缺失项记录 | 已整理 |

## 当前材料结论

目前能够确认并归档的是一个 GGUF 模型文件和 CodeTrack 项目源码。项目已经实现模型网关、OpenAI 兼容接口、课程知识库引用、AI 输出校验和规则兜底链路。

当前材料中没有发现独立的微调数据集、数据清洗脚本、训练脚本、训练超参数记录、训练日志、评测集、评测结果或可直接访问的模型 ServiceID。这些内容已经在 `03_数据与知识库材料`、`04_技术报告` 和 `05_复现说明` 中单独标注为待补充项。

源码归档提交时以 `01_作品源码/CodeTrack_源码_可复现版_提交版.zip` 为准。该压缩包已排除开发数据库、数据库备份、依赖缓存和 Python 临时文件。
